## Research context

Kexiang Wang's *A4S: Co-Designing Scaling and Placement in Stream Processing Systems with Memory-Parallelism Curves* (2023), chapter 4, describes an independent controller that reads job topology from the RisingWave Meta server, reads time-windowed task metrics from Prometheus, and sends its allocation to the Meta server's Reschedule API. The snapshot and execution boundary here keeps the same division of responsibility. Wang's model sizes task-local operator caches. Our initial Flink adapter wraps RocksDB block-cache MRCs on the legacy nominal axis and returns managed reservations. Wang's section 5.3 holds parallelism fixed while measuring profiler overhead, a useful control for isolating instrumentation effects. [Defense record](https://www.ece.utoronto.ca/graduates/oral-exams/) [Thesis PDF](https://utoronto.scholaris.ca/bitstreams/e0a39a88-27af-4859-b1c9-6a13b87b8ec4/download)

Ryan Li et al., *Efficient Autoscaling in Stream Processing Systems* (ECE496 final report, March 2026), sections 4.3–4.8, describe the Flink path from RocksDB instrumentation through per-vertex MergeMRC and the JobManager REST endpoint to an operator policy that starts from DS2 parallelism. The adapter retains those inputs and preserves the Flink execution authority. Figure 10 reports source throughput, managed memory and slots for Q8. Its resource-efficiency objective in section 5.2.6 was unmet. The runtime and operator revisions above describe the extracted code and its version pins.

Shafinul Haque, Peishuo Cai and Tom Nguyen, *Re-evaluating Autoscalers for Stateful Stream Processing Workloads in Apache Flink*, document their state-heavy Kafka and SQL workload in sections 4.2–4.3. Their DS2 and Justin comparison uses stateless upgrades and resets producer state between scaling periods. Section 5 evaluates SHARDS separately in RocksDB by comparing an uninstrumented build, online estimation and offline LRU replay. The verification report uses a continuous Kafka producer for checkpoint recovery and reports the native instrumentation experiment on its own workload.
